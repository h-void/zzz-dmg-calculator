# 绝区零 v3.3 智能配队 · 八维合轴 · UID 展柜与伤害精算台 (TypeScript + Web Worker)

模块化重构自单文件计算器的 **Vite + TypeScript + Web Worker** 纯前端工程，专为 **GitHub Pages** 零成本托管打造，集成微信小程序（如「绝区零工坊」）同款 **Enka.Network UID 展柜练度秒同步**、**驱动盘有效词条评级 (`ACE`/`SSS`/`SS`/`S`)** 与 **Web Worker 后台多线程驱动盘库配装寻优**。

## 核心特性

1. **微信小程序同款 UID 展柜一键同步 (`src/enka/`)**
   - 输入国服 / B服 / 国际服 UID，一键拉取游戏个人名片「代理人展柜」公开的 6 名角色（等级、影画 `M0~M6`、核心技 `A~F`、技能等级、音擎与精炼阶数、全套 `1~6` 号驱动盘主副词条命中次数）。
   - **增量合并本地练度柜**：在游戏内更换展柜角色后再次点击同步，自动合并进浏览器本地代理人练度柜与去重驱动盘池。
   - **驱动盘词条工坊评级**：按各代理人职业与转模模型（强攻 / 异常 / 命破 / 锋御 / 击破 / 支援 / 星见雅双暴异常混合）自动计算单盘与整套有效词条数并评定 `ACE` / `SSS` / `SS` / `S` / `A` / `B`。
   - **多格式背包扫描器兼容**：支持直接导入 `Enka JSON` 或 `GOOD` / `ZOD` / `AdeptiScanner-ZZZ` 等本地扫描器导出的驱动盘库 JSON。

2. **Web Worker 后台多线程计算 (`src/worker/`)**
   - **驱动盘池 6 盘组合寻优 (`OPTIMIZE_SLOT_FROM_POOL`)**：基于本地驱动盘池与队友防抢盘约束，在独立后台线程遍历 `4+2` 套装与散搭组合，直接以**当前全队实轴每秒真实 DPS** 为目标函数寻优，主界面全程 60fps 零卡顿。
   - **Box 智能搜队器 (`FIND_VIABLE_TEAMS`)**：后台线程并行遍历候选三人编队与八维合轴化学反应，支持直接套用练度柜已同步角色的真实面板与驱动盘。

3. **完整保留并类型化 v3.3 精算内核 (`src/engine/` & `src/data/`)**
   - 全量覆盖 **62 名代理人**、**103 把音擎**、**31 套驱动盘**、**20 只邦布**、**24 套热门公式配队**。
   - 完整八维合轴物理推演（脱手帧并行复用、无敌帧安全合轴 vs 裸露垫步、持续引导防断招、闪A振刀双反、支援点收支、手动双连携、99%压条瞬爆紊乱）与交互式多轨 SVG 排轴器。
   - 内置「全量自定义数据工坊」，支持可视化修改或新建任意角色、音擎、套装、邦布与深渊天气。

## 目录结构

```text
├── .github/workflows/deploy.yml   # GitHub Actions 自动构建并发布至 GitHub Pages
├── src/
│   ├── types/index.ts             # 全局 TypeScript 类型定义
│   ├── data/                      # 62角色 / 103音擎 / 31套装数据库与持久化 Store
│   ├── engine/                    # 八维合轴物理引擎与六乘区伤害模拟器
│   ├── enka/                      # Enka.Network UID 同步、ID 映射、词条评分与扫描器解析
│   ├── worker/                    # Web Worker 后台搜队与盘池配装寻优求解器
│   ├── ui/                        # 主工作台、UID 练度柜面板与全量自定义数据工坊
│   └── styles/                    # 高对比度工程表格暗黑/亮色双主题样式
└── vite.config.ts                 # Vite 构建与本地 /api/enka 反向代理配置
```

## 本地开发与构建

```bash
npm install
npm run dev       # 启动本地开发服务器 (内置 /api/enka 官方接口直连代理)
npm run typecheck # 运行 TypeScript 类型检查
npm run build     # 产出 dist/ 纯静态包 (可直接部署至 GitHub Pages)
```
