# ゼンレスゾーンゼロ v3.3 戦術編成・合軸精算スタジオ (`zzz-dmg-calculator`)

[简体中文](./README.md) · [English](./README.en.md) · **日本語**

**TypeScript + Vite + Web Worker** で構築された完全ローカル動作の『ゼンレスゾーンゼロ』編成・合軸タイムライン・ドライバディスク最適化スタジオです。**简体中文 / English / 日本語** のリアルタイム切替とライト/ダークテーマに対応しています。

- 🌐 **オンライン版**：<https://h-void.github.io/zzz-dmg-calculator/>

---

## 主な機能

- **全データ収録＆6大乗算区シミュレーター** — 62エージェント、103音動機、31ドライバディスク、20ボンプ、24定番編成プリセットを収録。直撃会心・属性異常/混沌・命破貫通・鋒御裂傷のダメージ計算および音動機・心象映画・次ガチャ1金 ROI 比較に対応。
- **リアルタイム乗算区希釈診断＆全環境・ボス耐性マトリクス** — 編成中の標準バフ限界上昇率、5番ディスク最適判定（属性ダメ vs 貫通率 vs 攻撃/HP/防御）、防御ダウン×貫通率の臨界点を即時計算し、6大ステージ環境＆8種ボス類型（高防御・耐性・短ブレイク・穢盾・異常耐性）の維持率をワンクリックで比較可能。
- **8次元合軸物理演算＆マルチトラック排軸シーケンサー** — 控え並列フレーム圧縮、無敵フレーム安全スワップ、手動ダブル連携、支援ポイント循環、短期バフ稼働率をインタラクティブなガントチャート上でシミュレート。
- **Enka.Network UID同期＆Web Workerバックグラウンド最適化** — UIDから名刺ショーケースの6名と1〜6番ディスクを取得（差分マージ保存＋`ACE`〜`B`スコア評価）。`GOOD` / `ZOD` / `AdeptiScanner-ZZZ` 形式のJSONインポートによる最適ディスク探索・所持Box編成検索にも対応。
- **カスタムデータ工房** — キャラ・音動機・セット効果・ボンプ・ボス耐性環境をブラウザ上で自由に編集・入出力可能。

## ローカル開発・ビルド

```bash
npm install
npm run dev           # 開発サーバー起動
npm run typecheck     # TypeScript 型チェック
npm run build         # dist/ へ静的バンドル出力
npm run calc:dilution # 全環境・全ボス・全62キャラ希釈レポートを再生成
```
